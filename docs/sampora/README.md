# Sampora Documentation Index

更新时间：2026-06-05

这个目录是当前 Sampora 官网、产品定位、SEO、术语和验收边界的 source of truth。旧的 `SurveySaaS`、`FenSvyG`、早期 demo 和归档文档仍可作为历史参考，但后续官网、销售材料、SEO 文案、JSON-LD、Codex patch 和 Agent 交接应优先遵循本目录。

## 必读顺序

1. [`current-product-positioning.md`](current-product-positioning.md)：当前品牌、目标客户、产品定位和不应误写的边界。
2. [`product-boundaries-and-workflows.md`](product-boundaries-and-workflows.md)：确认过的产品能力、业务闭环和外部合作资源转内部资源逻辑。
3. [`terminology-glossary.md`](terminology-glossary.md)：中英文固定术语，尤其是 `panel management software` 的中文口径。
4. [`seo-implementation-rules.md`](seo-implementation-rules.md)：SEO 关键词、OG/Twitter、JSON-LD、sitemap 和页面修改边界。
5. [`website-repair-and-acceptance-rules.md`](website-repair-and-acceptance-rules.md)：官网修复、回归保护和验收表述规则。

## 当前总判断

Sampora 不是普通问卷工具、普通项目管理系统、纯样本交易市场，也不应被包装成 Cint / PureSpectrum / Dynata 那类 marketplace。它更准确的定位是：

> Online sample operations platform and B2B SaaS workspace for panel providers, sample suppliers, supplier network teams, and market research sample operations teams.

中文可表达为：

> 面向自有样本库运营方、在线样本供应商、供应商网络团队和市场研究样本运营团队的在线样本运营平台 / B2B SaaS 工作台。

## GitHub 维护规则

- 本目录只写稳定共识，不写临时猜测。
- 商业敏感内容、支付费率、后台账号、合同信息、银行信息、客户名单不要写进公开文档。
- 若未来产品定位、定价、支付供应商或 SEO 页面策略发生变化，应先更新本目录，再让 Codex 或 Agent 改官网源码。
