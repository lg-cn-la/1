# Sampora 术语表与中英文固定口径

更新时间：2026-06-05

本文用于统一 Sampora 官网、SEO、Sales PDF、Demo、Codex patch 和 Agent 交接中的中英文术语。后续改文案时，优先按本文，不要机械直译。

## 1. 品牌与产品名

| English | 中文口径 | 使用规则 |
|---|---|---|
| Sampora | Sampora | 当前公开品牌。官网、SEO、JSON-LD、OG/Twitter、销售材料只用 Sampora。 |
| SurveySaaS | SurveySaaS | 历史旧名，只能用于旧资产说明和内部追溯。 |
| FenSvyG | FenSvyG | 历史旧名，只能用于旧 demo 或旧方向说明。 |

## 2. 核心定位词

| English | 中文口径 | 备注 |
|---|---|---|
| online sample operations platform | 在线样本运营平台 | 当前官网主定位，可用于 H1 / hero / footer。 |
| sample operations software | 样本运营软件 | SEO 必上词；中文不要写成“样本软件”。 |
| panel management software | 自有样本库管理软件 | 不要写成“Panel 管理软件”或“面板管理软件”。 |
| market research panel management software | 市场研究自有样本库管理软件 | 可用于 SEO / Plans / meta，不要全站高频重复。 |
| B2B SaaS workspace | B2B SaaS 工作台 | 可用于解释产品形态。 |
| operating layer | 运营层 / 运营工作层 | 用于表达跨项目、供应商、审核、财务的统一层。 |
| workspace | 工作台 | 比“平台后台”更适合官网表达。 |

## 3. 目标客户与角色

| English | 中文口径 | 备注 |
|---|---|---|
| panel provider | 自有样本库运营方 / Panel Provider | 强调拥有或运营自有 respondent / panelist 资源。 |
| sample supplier | 在线样本供应商 / 样本供应商 | 更大的样本供给方概念，可包含 Panel Provider。 |
| sample supplier platform | 样本供应商平台 | 可用于行业说明，但不要把 Sampora 写成纯 marketplace。 |
| supplier network team | 供应商网络团队 | 面向外部样本供应商管理团队。 |
| sample operations team | 样本运营团队 | 可用于泛称目标用户。 |
| market research sample team | 市场研究样本团队 | 用于补充行业上下文。 |
| research subcontractor | 调研分包执行团队 | 指承接上游项目并分发给下游供应商/执行团队的角色。 |
| sample aggregator | 样本聚合商 | 可以作为 Sample Supplier 的子类型。 |
| survey station | 调查站 / 执行单元 | 不优先用于首屏主定位，可用于说明样本供应方分类。 |
| API-connected supplier | API 对接供应商 | 指通过 API 接收/查看项目的供应商。 |

## 4. 流程与 SEO 关键词

| English | 中文口径 | 使用规则 |
|---|---|---|
| supplier routing workflow | 供应商路由流程 | SEO 必上词；可用于首页、Solutions、Resources、Contact。 |
| delivery review workflow | 交付审核流程 | SEO 必上词；可用于 Resources 和首页流程说明。 |
| settlement workflow | 结算流程 | SEO 必上词；可用于首页、Resources、Plans、Contact。 |
| sample delivery review workflow | 样本交付审核流程 | 可选长尾词，优先放 Resources。 |
| sample supplier settlement workflow | 样本供应商结算流程 | 可选长尾词，优先放 Resources / FAQ。 |
| supplier assignment | 供应商分配 | 产品能力词。 |
| supplier exclusion rules | 供应商排除规则 / 屏蔽规则 | 不要写成安全黑名单语气。 |
| supplier-specific pricing | 供应商级定价 / 供应商级项目价格 | 当前已确认能力。 |
| delivery evidence | 交付依据 / 交付证据 | 与结算和审核连接。 |
| settlement-ready records | 可结算记录 / 可用于结算的记录 | 比“自动结算完成”更稳妥。 |
| review records | 审核记录 | 与 callback、reject、termination、notes 连接。 |

## 6. 推荐公开版本名

| English | 中文口径 | 说明 |
|---|---|---|
| Sampora Panel | Sampora Panel / 自有样本库运营版 | 面向自有样本库运营。 |
| Sampora Supplier Network | Sampora Supplier Network / 供应商网络运营版 | 面向外部样本供应商与供应商网络运营。 |
| Sampora Enterprise | Sampora Enterprise / 企业版 | 面向多客户、多供应商、自有样本库、API、财务和权限的综合团队。 |

## 7. 不建议用语

- 不要把 `panel management software` 翻译为“Panel 管理软件”或“面板管理软件”。
- 不要把 `sample supplier` 全部翻成“样本商”这类口语词。
- 不要把 Sampora 写成“问卷系统”“调查问卷工具”“市场调查分析工具”。
- 不要把 Partner Network 写成普通“资源列表”或“黄页”。
- 不要在官网首屏优先使用 `Audience Source` / `Audience Owner`，这会过宽且不够贴近当前目标客户。
- 不要优先写 `Fieldwork Agency`，容易让海外用户联想到线下 fieldwork、CATI、CAPI。
