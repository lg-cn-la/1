# Sampora 当前产品定位共识

更新时间：2026-06-05

本文是后续官网、SEO、Sales PDF、Demo 脚本、Codex patch 和 Agent 交接的当前产品定位 source of truth。旧文档中的 `SurveySaaS` / `FenSvyG` / 早期 demo 名称只作为历史上下文，不再作为公开官网或销售材料的主品牌使用。

## 1. 当前品牌

- 当前公开品牌：**Sampora**
- 旧名：`SurveySaaS`、`FenSvyG`
- 旧名使用边界：只能用于历史资产说明、旧 demo 归档或内部追溯；不要出现在公开官网 title、H1、OG/Twitter、JSON-LD、sales copy 或 SEO 文案中。

## 2. 一句话定位

### English

**Sampora is an online sample operations platform and B2B SaaS workspace for panel providers, sample suppliers, supplier network teams, and market research sample operations teams.**

### 中文

**Sampora 是面向自有样本库运营方、在线样本供应商、供应商网络团队和市场研究样本运营团队的在线样本运营平台 / B2B SaaS 工作台。**

## 3. 不要误写成什么

Sampora 不应被定位为：

- 普通问卷编辑器或 SurveyMonkey / Typeform 竞品。
- 普通项目管理系统。
- 纯 sample marketplace。
- Cint / PureSpectrum / Dynata 那类样本交易市场。
- 研究报告、BI 洞察或市场分析工具。
- 传统线下 fieldwork / CATI / CAPI 访问员执行系统。

更准确的产品属性是：

> Sample Operations SaaS + Supplier Network Operations + Panel / Owned Sample Database Operations + Partner Network + Multi-party Settlement Workflow.

中文可表达为：

> 样本运营软件 + 供应商网络运营 + 自有样本库运营 + 合作资源网络 + 多方结算流程。

## 4. 目标客户

优先目标客户：

1. **Panel Providers / 自有样本库运营方**：拥有或运营自己的 respondent / panelist 资源，需要管理会员、画像、等级、激励、提现、项目分发和会员端入口。
2. **Sample Suppliers / 在线样本供应商**：为调研项目提供在线样本供给，可能拥有自有样本库，也可能依赖渠道、调查站、API 或合作供应商供样。
3. **Supplier Network Teams / 供应商网络团队**：需要管理外部样本供应商、供应商控价、屏蔽规则、交付追踪、审核、结算和账单。
4. **Research Subcontractors / 调研分包执行团队**：从上游客户承接项目，再分发给下游样本供应商、执行团队、Panel 或 API supplier。
5. **Customer-Supplier 双重身份团队**：既承接上游客户项目，又有自有样本或执行能力，还管理外部供应商。

## 5. 供应链位置

Sampora 位于在线样本供应链中的中间层与执行层：

```text
Brand / Research Company / Agency
  ↓ project or sample demand
Sample Operations Team / Research Subcontractor
  ↓ routing, supplier management, delivery review
Sample Supplier / Panel Provider / Execution Team
  ↓ respondents complete online surveys
Respondent / Panel Member
```

Sampora 管理的是问卷下游的在线样本交付链路：

```text
Project intake → Project setup → Supplier routing → Delivery tracking → Review → Settlement → Billing / invoices → Operational review → Partner Network growth
```

## 6. 当前官网主线

当前官网不是要继续做大量新页面，而是先让现有核心页面更准确地表达：

- Sampora 是 sample operations software。
- 面向 panel providers and sample suppliers。
- 覆盖 supplier routing workflow、delivery review workflow、settlement workflow。
- 支持 Partner Network 与 supplier / client cooperation。
- 不扭曲原有页面语义，不做 keyword stuffing。

## 7. 语言风格

英文：清楚、专业、B2B SaaS 风格，但不要过度官方化，不要写成空泛 enterprise jargon。

中文：自然、准确、内部可读，允许保留必要英文行业词，例如 Panel Provider、Sample Supplier、Partner Network、API supplier。不要把行业词机械翻译成不准确中文。
